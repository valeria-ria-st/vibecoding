Шаг 1: Основы Python

В Python всё строится на отступах. Простой вывод:

print("Привет, мир!")

Задание: Напиши код, который выводит фразу "Python — это просто!".


Шаг 2: Переменные и ввод

Переменные хранят данные, input() считывает ввод пользователя:

name = input("Как тебя зовут? ")
print("Привет,", name)

Задание: Считайте имя пользователя и выведите: "Рад видеть, [имя]!".


Шаг 3: Условные операторы

Условие if проверяет выражение:

age = int(input("Сколько тебе лет? "))
if age >= 18:
    print("Ты совершеннолетний")
else:
    print("Ещё рано")

Задание: Считай число и выведи "Число положительное", если оно больше 0, иначе "Не положительное".


Шаг 4: Циклы

Цикл for перебирает элементы:

for i in range(5):
    print(i)

Задание: Выведи числа от 1 до 5 (каждое с новой строки).


Шаг 5: Функции

Функции позволяют переиспользовать код:

def greet(name):
    return "Привет, " + name

print(greet("Анна"))

Задание: Напиши функцию square(x), которая возвращает квадрат числа, и выведи результат для x = 4.
